# Dazzy-Alaram

A custom-built desktop alarm clock powered by a Seeed Studio XIAO microcontroller and mechanical key switches. Built for DIY.

## Overview
Dazzy-Alaram is a custom hardware project designed from scratch. It combines a custom printed circuit board (PCB), mechanical switches for tactile input, and a 3D-printed enclosure to create a clean, functional desk clock.

*(Firmware disclosure: AI was used to assist in writing portions of the firmware code).*
